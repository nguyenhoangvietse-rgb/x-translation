This frontend handles the R2-based translation flow:

- Generate presigned upload URLs for `input/{job_id}/novel.txt`
- Poll `status/{job_id}.json`
- Download `output/{job_id}/translated.txt`

## Environment Variables

Create `frontend/.env.local`:

```bash
R2_ACCESS_KEY=...
R2_SECRET_KEY=...
CF_ACCOUNT_ID=...
R2_BUCKET=nover-files
```
